# <small>interface</small> SchemaField

## Properties
### <small>string</small> title
The title of the field. HTML can be used.
### <small>[SchemaFieldType](api/types/SchemaFieldType.md)</small> type
The type of the field.
### <small>Array</small> enum?
Can be an array of possible values, or an array of arrays where index 0 is the displayed title of the value to the user, and index 1 being the actual value.
